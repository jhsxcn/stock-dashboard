📖 板块强度轮动图使用说明

本页基于 KPL 板块强度评分（score） 每日收盘后生成，展示 A 股板块轮动状态。三项指标：强度 score（板块热度/资金综合分）、主力资金 fund（亿元，正=流入 负=流出）、涨幅 pct（%）。

视图看什么怎么判
📈 强度时序选一个板块，看其强度历史曲线连续上行=资金持续流入；高位横盘=警惕见顶；快速回落=退潮信号
📊 当日TOP某日强度 TOP12 排名+资金+阶段，点条形看成分股/领涨股长条+正资金=资金推动强；「高潮」却资金流出=谨防出货；「退潮」=回避
🔥 轮动热力图近20日全部板块强度横向对比（行=板块 列=日期，★今日=最新日）连续多日暖色=主线板块；暖转冷=资金撤离；冷转暖=启动信号

三、周期阶段判定规则

🟢 启动：板块首次上榜，排名暂无历史对比
🔵 扩散：排名上升 + 强度较前日涨 5% 以上 → 资金加速进场
🔴 高潮：连续多日位居前 3 → 主升中后段，追高风险加大
🟣 退潮：排名后退 3 名以上 或 强度跌 10% 以上 → 资金撤离
⚫ 冰点：排名跌至 8 名以后 → 冷门期，回避
🟡 震荡：其余情形，方向未明

四、用数据指导买卖（超短线框架）

① 选板块：score ≥ 10000 + 主力资金大幅流入（fund 为正且排名靠前）+ 阶段「启动/扩散」为最佳介入窗口。
② 选个股：点击板块条形 → 看成分股弹窗 → 选领涨股（涨幅居前）+ 叠加基本面过滤（净利润 > 0、非一字板、竞价涨幅 < 9%）。
③ 买点：扩散初期 / 回踩不破阶段支撑；回避「高潮」末端追高。
④ 卖点：强度从高位回落 10% 以上、主力资金转流出、板块「退潮」时减仓；热力图颜色由暖转冷是同步预警。
⑤ 风控：市场情绪冰点（TOP 强度普遍 < 5000）时降低仓位或空仓；个股严格止损。
